I like understanding how things work by building them from scratch. Most of my projects start from the question *"what's actually happening under the hood?"* — then I go implement it.

Right now I'm deep in the internals of **tokenization** (BPE, byte-level BPE, WordPiece) and building **from-scratch infrastructure** (Redis). Previously built AI agent frameworks, retrieval systems, and cryptographic primitives.
